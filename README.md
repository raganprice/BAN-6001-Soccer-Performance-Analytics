# English Premier League and Italian Serie A Performance Analytics

## About the Project

**Dataset:** Kaggle | **Topic:** Individual performance stats for players in English Premier League and Italian Serie A | **Size:** 1,160 rows x 15 variables

**Research Question:** 
Our team aimed to compare if meaningful differences exist between the two leagues to determine player performance and discipline, specifically yellow and red cards.

## Repository Structure

- `/[assignment-02-dataset]` — Original dataset with metrics
- `/[assignment-03-descriptive-stats]` — Descriptive stats for all variables, frequency tables for categorial variables, and data visualizations for all variables
- `/[assignment-04-probability]` — Distribution assessment and real-world probability questions
- `/[assignment-05-inference]` — Hypothesis testing and confidence intervals
- `/[assignment-06-regression]` — Model setup, the refinement process, and the final regression model
- `README.md` — Project guide
- `DECISIONS.md` — Data record of our analytical choices
